
# Dataset Dehazing - Kelompok 4

## 1. Deskripsi Dataset

Dataset Dehazing merupakan kumpulan pasangan gambar
yang terdiri dari citra berkabut (hazy) dan citra
jernih (clear).

Dataset ini dibuat untuk membantu proses penelitian
atau pengembangan teknologi penghilangan kabut pada
gambar (Image Dehazing).

Dataset terdiri dari minimal 50 pasangan gambar,
yaitu 50 gambar hazy dan 50 gambar clear.

---

## 2. Struktur Dataset

Dataset disusun dengan struktur folder berikut:

```text
Dataset_Dehazing/
│
├── hazy/
│   ├── 001_hazy.jpg
│   ├── 002_hazy.jpg
│   └── ...
│
└── clear/
    ├── 001_clear.jpg
    ├── 002_clear.jpg
    └── ...
```

---

## 3. Cara Mengunduh Dataset

1. Buka repository GitHub kelompok.
2. Klik tombol Code.
3. Pilih Download ZIP.
4. Ekstrak file ZIP yang sudah diunduh.
5. Dataset dapat digunakan melalui folder hazy
   dan clear.

---

## 4. Cara Menggunakan Dataset

Setiap gambar hazy memiliki pasangan gambar clear
dengan nomor yang sama.

Contoh:

- 001_hazy.jpg merupakan gambar berkabut.
- 001_clear.jpg merupakan gambar jernih.

Pasangan gambar tersebut dapat digunakan untuk
membandingkan kondisi gambar sebelum dan sesudah
proses dehazing.
